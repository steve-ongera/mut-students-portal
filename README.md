## The Problem We're Solving

Traditional university management systems fail students in critical ways:

1. **Information Overload Without Guidance**: Students struggle to navigate complex portals with hundreds of pages, not knowing where to find critical information when they need it most.

2. **Reactive Instead of Proactive**: Existing systems only show data but don't warn students about failing grades, approaching deadlines, or financial clearance issues until it's too late.

3. **No Personalized Support**: Every student gets the same generic portal experience regardless of their academic performance, financial situation, or personal circumstances.

4. **Limited Support Hours**: Student support offices close at 5 PM, leaving students stranded during evenings and weekends when they're most likely to need help.

5. **Mental Health Crisis**: Universities lack scalable ways to identify and support students experiencing stress, depression, or academic struggles before they drop out.

6. **Complex Processes**: Students waste time trying to understand procedures like unit registration, semester reporting, resit applications, and hostel booking without clear step-by-step guidance.

## Installation

### Prerequisites
- Python 3.8 or higher
- PostgreSQL 12+ (recommended)
- pip (Python package manager)
- Virtual environment
- Redis (for caching and Celery tasks - optional)

### Quick Start

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd mut-university-system
   ```

2. **Create and activate virtual environment**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure database settings**
   Edit `settings.py`:
   ```python
   DATABASES = {
       'default': {
           'ENGINE': 'django.db.backends.postgresql',
           'NAME': 'mut_db',
           'USER': 'your_username',
           'PASSWORD': 'your_password',
           'HOST': 'localhost',
           'PORT': '5432',
       }
   }
   ```

5. **Add context processor to settings.py**
   ```python
   TEMPLATES = [
       {
           'OPTIONS': {
               'context_processors': [
                   # ... existing processors ...
                   'your_app.context_processors.ai_chatbot_context',
               ],
           },
       },
   ]
   ```

6. **Run migrations**
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```

7. **Populate AI Knowledge Base**
   ```bash
   python manage.py populate_ai_knowledge
   ```

8. **Create superuser**
   ```bash
   python manage.py createsuperuser
   ```

9. **Run development server**
   ```bash
   python manage.py runserver
   ```

10. **Access the application**
    - Main Portal: http://localhost:8000/
    - Admin Panel: http://localhost:8000/admin/
    - AI Chatbot: Available on all pages (bottom-right corner)

## AI Configuration and Customization

### Knowledge Base Management
Add new knowledge through Django admin or programmatically:

```python
from your_app.models import AIKnowledgeBase

AIKnowledgeBase.objects.create(
    category='academic',
    question='How do I apply for academic leave?',
    answer='To apply for academic leave: 1. Download form from...',
    keywords=['academic leave', 'defer', 'suspension'],
    alternative_questions=[
        'Can I take a break from studies?',
        'How to defer my studies?'
    ],
    confidence_score=90.00,
    status='active',
    is_verified=True
)
```

### Customizing AI Responses
Edit `settings.py` to configure AI behavior:

```python
AI_CHATBOT_SETTINGS = {
    'ENABLED': True,
    'SESSION_TIMEOUT_HOURS': 24,
    'MAX_MESSAGE_LENGTH': 1000,
    'TYPING_DELAY_SECONDS': 1,
    'CONFIDENCE_THRESHOLD': 70,
    'PROACTIVE_ALERTS_ENABLED': True,
    'MENTAL_HEALTH_KEYWORDS': ['stress', 'depressed', 'anxious', 'suicidal'],
}
```

### Creating Proactive Alerts
```python
from your_app.models import ProactiveAIAlert, Student

# Alert students with low GPA
at_risk_students = Student.objects.filter(cumulative_gpa__lt=2.5)

for student in at_risk_students:
    ProactiveAIAlert.objects.create(
        user=student.user,
        student=student,
        alert_type='academic_risk',
        priority='high',
        title='Academic Performance Alert',
        message=f'Your GPA is {student.cumulative_gpa}. Consider academic support.',
        action_required='Schedule meeting with academic advisor',
        action_links=[
            {'url': '/counseling/', 'label': 'Book Counseling'},
            {'url': '/study-resources/', 'label': 'Study Resources'}
        ]
    )
```
